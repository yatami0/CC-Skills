# Report Skills

AIが書いた日本語は読めばすぐ分かる。文章を書く・直すときは以下のルールに従い、人間が書いたように自然な文章にする。
やり取り・成果物はすべて日本語で行う。文章を直すときは元の意味を変えない。

各ルールの Before/After つき変換例は [references/examples.md](references/examples.md) にまとめてある。
判断に迷ったとき、または既存文を直すときは、このファイルを読んでから作業する。

## 大前提 — 人は怠惰である

人間は怠惰なので、できるだけ簡単な書き方・言い回し・変換を選ぶ。
凝った表現や手間のかかる記号を避けるだけで、文章はかなり自然になる。まずこれを念頭に置く。

## 記号と表記

- **助詞を省略しない。** 日本語は助詞が重要。
- **冗長なカッコ補足をしない。** 前の語彙にカッコで言い換えを付けない（例「共通化（抽象化）」）。必要なときだけ。
- **余計な強調をしない。** `**` 太字はまず使わない。見出し代わりの太字も避ける。
- **人間が使わない記号を避ける。** `「」`・中点・emダッシュ（`—`）は使わない。中点は `/`、カッコは控えめに `""`。
- **番号をハードコードしない。** 見出しや段落の先頭に `1.` `1.1` を直接振らない。並列は標準のリスト記法で書く。
- **アスキーアートで図を描かない。** 図が必要なら Mermaid などコードで書く。

## 文のリズム

- **文末を単調にしない。** 同じ語尾を3回以上続けない。続いたら「だ」「体言止め」などで崩す。
- **接続詞を多用しない。** 「さらに」「また」「加えて」「したがって」を毎段落の頭に置かない。無くても繋がるなら削る。
- **段落の長さと閉じ方を揃えない。** 短い段落と厚い段落を混ぜる。毎回きれいに閉じない。

## 語彙と文体

- **受動態を過剰に使わない。** 「検討が行われた」を連発しない。能動態にする。
- **根拠のない評価語を使わない。** 「非常に」「重要」「本質的」「最適化」を避ける。根拠を添えるか、動詞中心の具体表現にする。
- **AI語彙を避ける。** 「包括的 / 革新的 / シームレス / 多角的 / 不可欠 / 示唆に富む / 興味深いことに」などは置き換えるか削除する。
- **三点セットを無理に作らない。** 何でも「A、B、C」の3項目に揃えない。自然な数にする。
- **言い換え連打をしない。** 同じ対象を「重要・大切・欠かせない」と繰り返さない。用語も統一する。
- **保険・ヘッジを常設しない。** 「一概には言えないが」を逃げ道に毎回置かない。条件があるなら具体的に書く。
- **定型の導入・締めを使わない。** 「参考になれば幸いです」「ポイントは以下の通り」「〜ではないだろうか」を避ける。

## 提出前の自己チェック

- [ ] 助詞を省略していない
- [ ] `**` 強調・見出し代わりの太字を使っていない
- [ ] `「」`・中点・emダッシュ・カッコ補足を多用していない
- [ ] 見出し・段落に番号をハードコードしていない
- [ ] アスキーアートで図を描いていない
- [ ] 同じ語尾が3回以上続いていない
- [ ] 「さらに」「また」「加えて」を連発していない
- [ ] 受動態を過剰に使っていない（能動態に直す）
- [ ] 根拠なき「非常に」「重要」「本質」がない
- [ ] AI語彙（包括的 / 革新的 / 示唆に富む 等）がない
- [ ] 定型の導入・締めの句がない
- [ ] 用語が統一されている（言い換え連打がない）
