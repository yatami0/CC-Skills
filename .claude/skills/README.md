# .claude/skills/

このディレクトリは、このリポジトリ専用の **Claude Code Skill**（プロジェクトスコープ）を蓄積する場所。

1 スキル = 1 ディレクトリ = 1 `SKILL.md`：

```
.claude/skills/
└── <skill-name>/
    └── SKILL.md
```

背景・仕組み・使い方・カタログ・**新しい Skill の追加手順**は、正本ガイドにまとめている:

→ [doc/skills.md](../../doc/skills.md)

新しい Skill を作ったら、`doc/skills.md` の「カタログ」表に 1 行追加すること。
