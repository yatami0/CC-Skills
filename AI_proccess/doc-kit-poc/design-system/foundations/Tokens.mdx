# Tokens（① Foundations）

UI が直接使ってよいのは **semantic** だけ。primitive（`--ref-*`）は参照専用、
component（`--callout-*` 等）はその部品の中だけ。下記はすべて `var(--token)` で実描画しており、
ツールバーの **Theme** を dark に切り替えると semantic 色が runtime で追従する。

## 色（semantic）

`@theme inline` で公開された semantic 色。dark は素名 semantic（`--bg` 等）だけ上書きする。
