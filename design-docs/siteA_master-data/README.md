# サイトA（master-data）

第2層：標準フォルダ体系（`00_standards/design_architecture.md` §4）に従って埋めるサイト設計書。

## フォルダ

| 番号 | フォルダ | 内容 |
|------|---------|------|
| 01 | キャッチアップ | ドメイン知識・前提・用語 |
| 02 | 環境構築 | ローカル構築手順 |
| 03 | 開発規約 | Gitフロー・リリース・CI/CD |
| 04 | アーキテクチャ | このサイト固有の構成図・認証・外部連携（横断ルールは `00_standards/fe-architecture.md` / `be-architecture.md` を参照） |
| 05 | UI設計 | Figma のパス |
| 06 | 画面設計書 | `screen-list.md` + 画面別設計書 |
| 07 | **メタデータ定義設計** | ★サイトA固有（標準には無い）。メタデータ駆動・EAV 等はこの第2層に閉じる |
| 08 | API設計書 | `openapi.yaml` + BL設計 |
| 09 | データモデル | ERD・テーブル定義 |
| 10 | 区分値設計 | 区分値（ENUM）の正本 |
| 11 | メッセージ定義 | メッセージの一元管理 |

> `07_メタデータ定義設計` を挿入したため、以降の番号が標準とずれる。これは許容（`naming_convention.md` §1）。
> 各成果物は `00_standards/templates/` を複製して作成し、`document_guideline.md` に従って埋める。
