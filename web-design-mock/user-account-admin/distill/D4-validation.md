### 不足の詳細(同型 × 不足 → 哲学の穴)
- **不足#1(軽微): font の CJK デルタ欠落**
  ソース mock-v6 は `--font-sans` に **"Noto Sans JP"** を挿入していた(D1 §1.1)。aux-admin.md は
  これをデルタに入れ忘れ、base(apple)の font をそのまま使用。Hiragino 等の base CJK で機能代替は
  効くが、**ソースの意図した日本語フォントは再現できていない**。
- **不足#2(本質的): mono フォント + 密データ規約の不在**
  監査ログは IP / API キー / ID / タイムスタンプが密。これらを等幅で見せたく、ジェネレータは
  `font-family: ui-monospace,…` を**ハードコードせざるを得なかった**(anti-slop T1 で検出)。
  哲学は「得意=データテーブル」を主張するのに、**密データの等幅/タブ揃え規約を持っていない**。
  → ソースの user-list 画面に等幅データが無かったため、D1→D3 で取りこぼした穴。**別コンテンツの
  同型で再生成したからこそ露呈**した(D4 の狙いどおり)。

## ドッグフーディング所感(D4 設計の手応え)
- **D4 は設計どおり機能した**: 「別コンテンツの同型」で回したことで、ソース画面に無かった
  **mono/密データ規約の穴**を炙り出した(同一画面の再生成では絶対に出ない)。
- **循環防御が効いた**: ソース HTML を見ずに哲学だけから組ませ、足りない所をジェネレータが捏造 →
  anti-slop が機械検出 → 「不足」として可視化。**哲学の穴とジェネレータの有能さを分離**できた。
- **失敗マトリクスが効いた**: 「崩れた」を曖昧に終わらせず、`同型 × 不足` と即断 → D3 差し戻しへ
  一意に落ちた。
- **示唆**: D4.3 項目1(トークン被覆)は **anti-slop の T1(font ハードコード)が部分的に機械化**して
  いる。「哲学に無い :root 追加の有無」チェックを足せば、被覆の半機械化がさらに進む(設計 §9 へ)。
