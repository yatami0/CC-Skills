# フェーズ2 — 基本設計(画面骨格)

> 哲学・対象・スコープは 01-requirements.md を参照(再掲しない)。哲学 = IBM Carbon。
> 本フェーズは**骨格レベル**のみ。色/余白/影などの細かいスタイリングはフェーズ3で行う。

## 1. 画面レイアウト骨格(Carbon 2x Grid / 面の階層)

この画面は **汎用の「管理データ一覧ビュー」**。サイドナビが**管理データ項目のリスト**で、
選択した項目によって**右側テーブルの中身(表示するデータ種別)が切り替わる**。
今回のモックでは「ユーザー / アカウント」項目を選択中の状態を描く。

```
┌───────────────────────────────────────────────────────────────────────┐
│ ヘッダーバー (UI Shell header)  製品名 / グローバル領域(ユーザーメニュー) │  ← --background
├──────────┬────────────────────────────────────────────────────────────┤
│          │  ツールバー: [検索ボックス]      [ロール▾] [ステータス▾]      │  ← table toolbar
│ サイド    │ ───────────────────────────────────────────────────────── │
│ ナビ      │  ┌─ データテーブル ───────────────────────────────────────┐ │
│ (管理     │  │ 名前 | メール | ロール | ステータス | 最終ログイン        │ │  ← 表ヘッダ
│  データ    │  │ ──────────────────────────────────────────────────── │ │
│  項目)    │  │ 行(クリックで右パネル) … ゼブラ/罫線で密度を確保        │ │
│          │  │  …                                                      │ │
│ ・ユーザー │  └──────────────────────────────────────────────────────┘ │
│   ←選択中 │  ページネーション: 件数 / ページ送り / 表示件数              │
│ ・(他項目)│                                                            │
└──────────┴────────────────────────────────────────────────────────────┘
            ↑ 項目選択で右の一覧が切替          ↑ 行クリックで右スライドパネル(詳細)が重なる
```

- **サイドナビ = データ切替**: 各項目が管理対象データ種別。選択中の項目が
  選択状態(`--layer` の段差 + 左アクセントバー)で示され、右テーブルの内容を決める。
- **コンテンツ上部にページ見出し/件数・追加ボタンは置かない**(ユーザー要望で削除)。
  コンテンツ領域の先頭は**ツールバー(検索 + フィルタ)**から始まる。
- **面の階層(Carbon 核心)**: ページ = `--background`(白)。サイドナビ/ツールバー帯は
  `--layer-01`(Gray10)で面を一段持ち上げる。テーブルは白面。影は使わず段差で表現。
- **グリッド**: lg(1056px+, 16列)を標準。サイドナビ固定幅 + 残りをコンテンツ領域。
- **コントロール高さ**: ツールバー/テーブルは高密度寄りに sm〜md。

## 2. 画面構成要素(載せる / 削る)

### 載せる
| 要素 | 内容 |
|---|---|
| ヘッダーバー | 製品名、右側にユーザーメニュー(プレースホルダ)。Shell header 規約。 |
| 左サイドナビ | **管理データ項目のリスト**。選択した項目で右テーブルの内容が切替。「ユーザー」を選択状態に。他項目はダミーで階層感を出す。 |
| ツールバー | コンテンツ先頭。**キーワード検索ボックス** + **ロール フィルタ** + **ステータス フィルタ**。 |
| データテーブル | 下記カラム。**ゼブラ/罫線**で高密度可読。行ホバー + クリックで詳細。 |
| ステータス表示 | support トークンの色 + ラベル(色のみに依存しない=a11y)。 |
| ページネーション | 総件数 / ページ送り / 1ページ表示件数セレクタ。 |
| 詳細パネル | **右スライドオーバーパネル**(行クリックで開く)。下記 §4。 |

### 削る(スコープ外)
- **ページ見出し(「ユーザー管理」+件数)= なし**(ユーザー要望)。
- **「ユーザー追加」ボタン = なし**(ユーザー要望。フェーズ1の「新規追加」選択を取消)。
- 一括操作(チェックボックス列・バルクツールバー)= **なし**(01 で確定)。
- 行アクションメニュー(行内の編集/無効化オーバーフロー)= **なし**(01 で確定)。

## 3. データテーブル カラム(確定)

| # | カラム | 内容 / 表現 | 備考 |
|---|---|---|---|
| 1 | 名前 | 氏名(+ 任意でアバターイニシャル) | 主キー的に最左 |
| 2 | メール | username@example.com | mono 寄りで桁を揃えても可 |
| 3 | ロール | **管理者 / 一般** | タグ or テキスト(詳細設計で確定) |
| 4 | ステータス | **有効 / 無効 / 招待中** | support 色 + ラベル(色のみ依存しない) |
| 5 | 最終ログイン | 日時(相対 or 絶対) | 未ログインは「—」 |

- 行アクション列は持たない(行全体がクリック可能 → 詳細パネル)。
- ステータス3種の色マッピング案: 有効=success / 無効=gray(中立) / 招待中=warning。
  ※ 正確なトークン割当はフェーズ3で確定(accent と競合させない)。

## 4. 詳細表示の方式(要確定)

**既定案: 右スライドオーバーパネル**(Carbon の定番。一覧の文脈を保ったまま詳細を見られる)。
- 行クリックで右から重なって出現。閉じる(×)で一覧に戻る。背面は薄く覆う。
- パネル内容(骨格): 氏名 / メール / ロール / ステータス / 最終ログイン / 作成日 などの
  読み取り項目。編集や無効化アクションは今回スコープ外のため**閲覧主体**。

> 代替: ①別画面遷移(詳細ページ) ②中央モーダル。
> 一覧作業の流れを切らない右パネルを推奨。希望があればゲートで指定を。

## 5. レスポンシブ骨格(Carbon ブレークポイント)
- lg+ (1056px〜): サイドナビ常時表示 + テーブル全カラム。
- md (672–1055px): サイドナビは折りたたみ可。テーブルは横スクロール許容。
- sm (320–671px): サイドナビをオフキャンバス化。テーブルは主要カラム優先 + 横スクロール。
